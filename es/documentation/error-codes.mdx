### Formato de Respuesta de Error

Todos los errores se devuelven en formato JSON con los campos `code` y `message`.

**Por ejemplo:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Tabla de Errores de la API de ER:LC

Estos códigos de error pueden ser devueltos por la API externa de ER:LC al realizar solicitudes a los endpoints `*/erlc/*`.

<AccordionGroup>
  <Accordion title="Errores del Sistema (0, 1001, 1002)">
    | Código | Significado |
    | ------ | ----------- |
    | `0`    | Ocurrió un error desconocido. Si el error persiste, contacta al soporte de ER:LC Rusia mediante un ticket (nos comunicaremos con el soporte de PRC si el error ocurre con frecuencia). |
    | `1001` | Error de comunicación con Roblox o con el servidor privado dentro del juego. |
    | `1002` | Ocurrió un error interno del sistema. |
  </Accordion>

  <Accordion title="Errores de Autenticación (2000–2004)">
    | Código | Significado |
    | ------ | ----------- |
    | `2000` | No proporcionaste una clave de servidor (server-key). |
    | `2001` | Proporcionaste una clave de servidor en un formato no válido. |
    | `2002` | Proporcionaste una clave de servidor no válida o vencida. |
    | `2003` | Proporcionaste una clave de API global no válida. |
    | `2004` | Tu clave de servidor tiene el acceso a la API bloqueado. |
  </Accordion>

  <Accordion title="Errores de Solicitud (3001–3002)">
    | Código | Significado |
    | ------ | ----------- |
    | `3001` | No especificaste un comando válido en el cuerpo de la solicitud. |
    | `3002` | El servidor al que intentas acceder está desconectado actualmente (sin jugadores). |
  </Accordion>

  <Accordion title="Errores de Límite de Frecuencia y Acceso (4001–4003)">
    | Código | Significado |
    | ------ | ----------- |
    | `4001` | Límite de frecuencia de solicitudes superado. |
    | `4002` | El comando que intentas ejecutar está restringido. |
    | `4003` | El mensaje que intentas enviar está prohibido. |
  </Accordion>

  <Accordion title="Códigos Especiales (9998, 9999)">
    | Código | Significado |
    | ------ | ----------- |
    | `9998` | El recurso al que intentas acceder está restringido. |
    | `9999` | El módulo en el servidor del juego está desactualizado. |
  </Accordion>
</AccordionGroup>

## Manejo del Código `0`
Si encuentras un error con el código `0` (Error Desconocido) y persiste a lo largo de varias solicitudes consecutivas, crea un ticket en nuestro servidor de Discord. Adjunta los detalles de tu solicitud al ticket para que nuestro equipo pueda investigar el problema.
