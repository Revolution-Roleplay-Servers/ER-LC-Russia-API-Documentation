**La API de ER:LC Rusia** es una potente interfaz para desarrolladores que proporciona acceso a las funciones de nuestra comunidad y permite la interacción en tiempo real con el sistema técnico del proyecto, incluida la gestión de servidores de juego, la economía y otras capacidades.


## ¿Quién puede usarla?

Cualquier desarrollador que trabaje con la API de ER:LC Rusia puede obtener acceso después de que se revise su ticket. Se emite una clave de autenticación tras la aprobación de la solicitud.
<Note>
  **Si no eres desarrollador y no trabajas con APIs, esta documentación no es para ti. En su lugar, utiliza una de las aplicaciones asociadas ya preparadas que se indican a continuación.**
</Note>
