### Formato della Risposta di Errore

Tutti gli errori vengono restituiti in formato JSON con i campi `code` e `message`.

**Ad esempio:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Tabella degli Errori dell'API ER:LC

Questi codici di errore possono essere restituiti dall'API esterna di ER:LC durante le richieste agli endpoint `*/erlc/*`.

<AccordionGroup>
  <Accordion title="Errori di Sistema (0, 1001, 1002)">
    | Codice | Significato |
    | ------ | ----------- |
    | `0`    | Si è verificato un errore sconosciuto. Se l'errore persiste, contatta il supporto di ER:LC Russia tramite ticket (contatteremo il supporto PRC se l'errore si verifica frequentemente). |
    | `1001` | Errore di comunicazione con Roblox o con il server privato di gioco. |
    | `1002` | Si è verificato un errore di sistema interno. |
  </Accordion>

  <Accordion title="Errori di Autenticazione (2000–2004)">
    | Codice | Significato |
    | ------ | ----------- |
    | `2000` | Non hai fornito una server-key. |
    | `2001` | Hai fornito una server-key in un formato non valido. |
    | `2002` | Hai fornito una server-key non valida o scaduta. |
    | `2003` | Hai fornito una chiave API globale non valida. |
    | `2004` | La tua server-key è bloccata dall'accesso alle API. |
  </Accordion>

  <Accordion title="Errori di Richiesta (3001–3002)">
    | Codice | Significato |
    | ------ | ----------- |
    | `3001` | Non hai specificato un comando valido nel corpo della richiesta. |
    | `3002` | Il server che stai tentando di raggiungere è attualmente offline (nessun giocatore). |
  </Accordion>

  <Accordion title="Errori di Rate Limit e Accesso (4001–4003)">
    | Codice | Significato |
    | ------ | ----------- |
    | `4001` | Limite di richieste superato. |
    | `4002` | Il comando che stai tentando di eseguire è limitato. |
    | `4003` | Il messaggio che stai tentando di inviare è proibito. |
  </Accordion>

  <Accordion title="Codici Speciali (9998, 9999)">
    | Codice | Significato |
    | ------ | ----------- |
    | `9998` | La risorsa a cui stai accedendo è limitata. |
    | `9999` | Il modulo sul server di gioco non è aggiornato. |
  </Accordion>
</AccordionGroup>

## Gestione del Codice `0`
Se riscontri un errore con codice `0` (Unknown Error) e persiste per più richieste consecutive, apri un ticket sul nostro server Discord. Allega i dettagli della richiesta al ticket in modo che il nostro team possa analizzare il problema.
