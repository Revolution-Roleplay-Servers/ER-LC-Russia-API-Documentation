### Формат Відповіді Про Помилку

Усі помилки повертаються у форматі JSON із полями `code` та `message`.

**Наприклад:**
```json
{
  "code": 5007,
  "message": "Missing Token"
}
```

## Обробка Коду `0`
Якщо ви отримуєте помилку з кодом `0` (Unknown Error) і вона повторюється при кількох запитах поспіль, створіть тікет на нашому Discord-сервері. Прикріпіть до звернення деталі вашого запиту, щоб наша команда могла розібратися, у чому проблема.
