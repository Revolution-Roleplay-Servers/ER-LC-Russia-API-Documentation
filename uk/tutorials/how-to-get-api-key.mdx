title: "Як отримати API ключ?"
description: "Покроковий посібник з отримання API ключів, доступу до WebSocket та керування вебхуками."
---

Для інтеграції з нашими сервісами вам знадобляться відповідні доступи та ключі авторизації. Зверніть увагу, що доступ до HTTP API, WebSocket-серверів та керування вебхуками розділено з міркувань безпеки.

## Отримання Доступу

<Steps>
  <Step title="Відкриття Тікета">
    Для первинного отримання доступу до HTTP API, WebSocket або до системи керування вебхуками вам необхідно **відкрити тікет на нашому Discord-сервері**. Опишіть ваш проєкт та вкажіть, які саме можливості та доступи вам знадобляться для реалізації.
  </Step>
  <Step title="Схвалення Заявки">
    Дочекайтеся, поки адміністрація проєкту розгляне ваше звернення. Після схвалення вашої заявки до вашого Discord-акаунта будуть прив'язані відповідні права доступу.
  </Step>
  <Step title="Перегляд та Керування Ключами">
    Щойно права будуть видані, ви зможете генерувати, переглядати та керувати своїми токенами прямо всередині Discord-сервера за допомогою слеш-команд.
  </Step>
</Steps>

## Доступні Типи Ключів та Команди

### 1. HTTP API Ключ
Основний токен, який використовується для надсилання стандартних HTTP-запитів до наших ендпоінтів. Передається в заголовку `Authorization`.
* **Команда для перегляду:** `/апи просмотр`

### 2. WebSocket Ключ
Для роботи з подіями в реальному часі використовується **окремий незалежний ключ**. Не намагайтеся використовувати стандартний HTTP-токен для підключення до сокетів — сервер його відхилить.
* **Команда для перегляду:** `/вебсокет просмотр`
<Danger>
  **Завжди тримайте ваші ключі в секреті. Ключі від WebSocket та HTTP API абсолютно автономні та керуються незалежно один від одного.**
</Danger>

## Керування Вебхуками

Якщо вашому сервісу необхідно отримувати автоматичні сповіщення про події на сервері, ви можете налаштувати вебхуки. 

Доступ до панелі керування вебхуками також видається **суворо через тікети** в адміністрації проєкту. Щойно права будуть прив'язані до вашого акаунта, вам стане доступна спеціальна команда для налаштування:

* **Команда для керування:** `/вебхук управление`

<Tip>
  **При використанні цієї команди бот відкриє зручне меню, де ви зможете прив'язувати, видаляти та переглядати активні URL-адреси для надсилання вебхуків.**
</Tip>
